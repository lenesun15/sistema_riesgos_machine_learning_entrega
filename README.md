# Sistema de Clasificación del Nivel de Riesgo de los Activos de Información mediante Machine Learning

## 1. Descripción del proyecto

Este proyecto académico tiene como finalidad desarrollar un sistema para clasificar el nivel de riesgo de los activos de información mediante técnicas de Machine Learning, aplicado a la Carrera de Ingeniería de Sistemas Informáticos de la Universidad Boliviana de Informática (UBI).

El sistema busca apoyar la identificación y clasificación de riesgos asociados a los activos de información y contribuir a la toma de decisiones en seguridad de la información.

## 2. Objetivo general

Desarrollar un sistema basado en Machine Learning que permita clasificar el nivel de riesgo de los activos de información.

## 3. Tecnologías utilizadas

- Lenguaje de programación: Python.
- Modelo de clasificación: Random Forest Classifier.
- Tipo de aprendizaje: supervisado.
- Datos: conjunto de datos sintético con fines académicos.

## 4. Metodología

1. Preparación y revisión de los datos.
2. Selección de características.
3. Preprocesamiento del conjunto de datos.
4. Entrenamiento del modelo de Machine Learning.
5. Clasificación del nivel de riesgo.
6. Evaluación de los resultados.

## 5. Instalación

Crear un entorno virtual con Python:

```bash
python -m venv .venv
```

Activarlo en Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Instalar las dependencias del proyecto:

```bash
python -m pip install -r requirements.txt
```

El comando de ejecución depende de los archivos y del punto de entrada implementado. Se debe revisar el código fuente para determinar cómo entrenar el modelo y ejecutar la aplicación.

## 8. Limitaciones

El conjunto de datos sintético permite realizar pruebas académicas, pero no representa por sí mismo los riesgos reales de los activos institucionales. Para una aplicación real se requieren datos validados y criterios de evaluación adecuados.
